# Productionization 8-hour plan

Date: 2026-05-31
Branch: `fix/multilevel-cascade-regression`

## Refined definition of done

A production output is functional when it can be generated by a documented
command, opened or decoded by the expected toolchain, and backed by committed
receipts or benchmark logs. A pipeline is production-ready when all of these
are true:

1. `pipelines/registry.json` passes `check_registry_consistency.py --strict-artifacts`.
2. Every `ship-*` registry role has an exact committed `tests/quality_gates/runs/<hash>/run.json` receipt with `verdict=PASS`.
3. Release candidates additionally pass `audit_ship_pipelines.py --strict`: current `gates.json` hash and a `docs/claims_log.md` entry for the same pipeline/run hash.
4. Stills output is functional: primary/smallest/archival STILL roles have PASS receipts and decode paths remain covered by CI.
5. Video quality output is functional: VIDEO_FREEZE roles have PASS receipts; PREVIEW chroma either passes or has a fully documented root cause and a concrete fix path.
6. Video containers are functional: `.gvid` and `.gpraw.mov` have pack/read or decode smoke coverage, and GPRaw handoff paths are documented.
7. UPRESABLE output is functional: half-res Pi capture, Mac BIBO_2x upres, full-res `.gpr`, optional DNG export, and GPRaw pack all have commands and receipts.
8. Pi 5 / GoPro Mission 1 deployment is functional: SD/SSH setup, build/deploy, capture benchmark, transfer, and Mac post path are scripted or documented with a pass/fail checklist.
9. Operations dashboards are generated from committed data or explicitly marked local-only.
10. CI protects the production metadata path and is green after each productionization commit.
11. Any visual-quality claim still follows the root `CLAUDE.md` rule: run the full gate and inspect the worst visual diff before claiming.

## Chroma definition of done

Chroma is done when one of these is true:

1. A registered chroma-corrected PREVIEW pipeline clears the full quality gate,
   has checkpoint hashes in `models/`, has the worst visual diff inspected, and
   can be claimed through `run_gate.py --claim`.
2. If it cannot pass inside the 8-hour window, the root cause is nailed down to
   a specific failing stage with reproducible evidence: codec Bayer chroma,
   naive demosaic chroma, YCbCr decomp, Lab assembly, or checkpoint objective.
   The evidence must include per-image Lab a/b bias, a/b correlation, hue error,
   dE95, and at least one visual diagnostic dashboard.

# Pi 5 sustained encode bench — 2026-05-26

Historical receipt. This run is kept because it explains the original
half-res capture budget, but it is not the current production claim. Current
Labs evidence lives in `docs/LABS_TARGET_BENCH.md` and
`docs/LABS_PI_CAPTURE_REGRESSION_2026-06-15.md`: the strict 10 minute Pi proxy
receipt is 19.98 fps median with 0 drops and valid `.gvid`, and Mission 1
hardware still needs a 24 fps target receipt.

Pi: pi5-capture, Cortex-A76 ×4, kernel 6.12.75-1+rpt1, USB SSD at /mnt/ssd.
Branch: fix/multilevel-cascade-regression (commit be0328a + downstream).
Method: 100-frame sustained, defeats page cache, includes fwrite to USB SSD.

## Full 50 MP (8280×5520, no decimation)

```
GPR_INCLUDE_LL=1 FUSED_MULTI_LEVEL=1 FUSED_WAVELET_LEVELS=2 \
GPR_BENCH_WRITE_ALL=/mnt/ssd/bench_out_ml2 \
  bench_fused test_50mp.raw 8280 5520 100
```

mean=142.66ms  stddev=20.27  min=117.34  median=138.99  max=189.88
fps_mean=7.01  **fps_median=7.19**  fps_p25(fast)=7.99
output frame mean: 3.64 MB
24 fps would write 87 MB/s (requires a measured storage path above that rate,
for example USB SSD or NVMe)

**Verdict: 7.19 fps. 24 fps target NOT achievable on Pi 5 with full 50 MP encode.**

## Half-res (decimate=2, 12.5 MP equivalent) — the historical capture mode

```
GPR_INCLUDE_LL=1 FUSED_MULTI_LEVEL=1 FUSED_WAVELET_LEVELS=2 \
GPR_COL_DECIMATE=2 GPR_ROW_DECIMATE=2 \
GPR_BENCH_WRITE_ALL=/mnt/ssd/bench_out_ml2_dec2 \
  bench_fused test_50mp.raw 8280 5520 100
```

mean=41.38ms  stddev=2.74  min=37.79  median=40.11  max=47.72
fps_mean=24.17  **fps_median=24.93**  fps_p25(fast)=25.49
output frame mean: 953 KB
24 fps would write 22.9 MB/s (any consumer storage)

**Historical verdict: 24.93 fps on this older branch/run. Current `master`
does not use this number as a production claim.**

## What this reproduces

The historical 23.94 fps memory note was for 2-level wavelet + decimate=2 on
the same Pi 5 hardware. This May 26 result matched and slightly exceeded it,
but later clean Labs receipts did not reproduce the number.

## Architecture confirmed

- Pi 5 / embedded: half-res ML-2 q=3 capture, codec-only, ~25 fps × 50 MP raw
- Desktop / post: read .gpr, decode, apply BIBO_2x super-res CNN, restore 50 MP

Current deployment framing is in `docs/VIDEO_STATUS.md`,
`docs/LABS_TARGET_BENCH.md`, and `docs/LABS_MISSION1_RUNBOOK.md`.
